# CursorChanger

마비노기 모바일 프로그램을 감지하면 커서가 변경되는 프로그램을 개발중입니다.

현재 프로그램 트레이에 표시되도록 설정완료 되었습니다.
    custom_cursors 폴더에 사용하고 싶은 디자인의 .cur 파일 또는 .ani 의 파일을 넣어두거나 트레이에서 커서파일변경으로 사용하시면 됩니다.

마비노기 종료 후 다시 커서는 원래대로 변경되게 수정하였습니다.

(2025.05.10 업데이트 내용)-----------------------------
현재 Installer로 패키징

인스톨 당시 한번 실행하면 이 후 삭제 하기전까지 pc 실행시 자동으로 실행되도록 수정.

installer로 다운받을 경우 uninstall.exe 추가

.ani 파일만 감지하는 버그 수정(.cur 도감지)

(2025.05.11 업데이트 내용)-----------------------------


기본 윈도우 커서로 변경할 수 있도록 핫키 추가 (Ctrl + F12)

좌측 프로그램 트레이(윈도우 시계 부분 옆 위치) 우클릭시 커서 기본 윈도우 커서로 변경할 수 있도록 ON/OFF 기능 추가 

커서 디자인 추가(C:\Users사용자\AppData\Local\MabinogiCursor\custom_cursors 에서 커서 디자인 선택하여 사용하면 됩니다.)

커서 변경후 저장하는 기능 추가(프로그램 및 PC 재 시작해도 변경상태로 유지) 폴더는 처음 설치시 해당 위치에 설치

C:\Users사용자\AppData\Local\MabinogiCursor  변경시 프로그램 실행 어려울 수 있음.

해당 폴더에 uninstaller 추가.
